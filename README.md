# Bangladesh 2.0

A responsive landing page that presents a vision for **Bangladesh 2.0**, focusing on innovation, sustainability, infrastructure, digital transformation, green energy, and inclusive development.

The project is built as a static frontend using **HTML5 and CSS3**, with a clean, structured layout designed for modern web experiences.

## Overview

**Bangladesh 2.0** is a frontend landing page that highlights ideas and initiatives for a future-ready Bangladesh.

The website includes multiple content-driven sections covering:

* Bangladesh 2.0 vision
* Development pillars
* Future initiatives
* Digital transformation
* Green energy
* Modern infrastructure
* Public opinion
* Recent news
* Donation section
* Newsletter subscription
* Social media links

The project focuses on responsive layout, semantic HTML structure, reusable CSS styling, and modern frontend design principles.

## Getting Started

### Prerequisites

No framework, package manager, or backend server is required.

You only need a modern web browser.

### Clone the Repository

```bash
git clone https://github.com/mrshanshuvo/bangladesh-2.0.git
```

Navigate to the project directory:

```bash
cd bangladesh-2.0
```

### Run the Project

Since this is a static HTML/CSS project, you can open `index.html` directly in your browser.

For a better development experience, you can also use **VS Code Live Server** or another local static server.

## Development

The main entry point is:

```text
index.html
```

Styles are maintained in:
